## 1. 产品定义

**一句话**：装在家人手机上的位置共享 App，配合自建服务器与网页端，随时看到家人在哪。

**目标用户**：2–10 人的家庭。典型成员：主要查看者（上班族）、老人、孩子、伴侣。

**核心场景**：

1. **接送 / 晚归确认**：打开 App 或网页，一眼看到家人当前位置和更新时间。
2. **说不清位置**：老人孩子不会描述地点，直接看地图和地址。
3. **紧急找人**：点「立即定位」，让手机做一次高精度定位并马上回传。

**与现成产品的差异**：位置数据存在自己家中的服务器上；上报频率、历史保留、提醒规则都可自己定。

**设计原则**：

- **知情共享**：开启时明确告知，常驻通知可见，随时可暂停。
- **省电优先**：静止时降频、移动时升频，默认「标准」档。
- **弱网可用**：本地缓存位置，恢复网络后补传；界面始终显示数据新鲜度。
- **隐私最小化**：只采集位置、电量、精度等必要字段；成员只能看到同一家庭的数据。

**本期不做**：iOS、聊天、地理围栏、SOS、多家庭、位置导出、深色模式（P1 再评估）。

## 2. 平台矩阵

| 端 | 使用者 | 核心职责 | 形态 | 技术 |
|---|---|---|---|---|
| Android App | 家庭成员 | 上报位置、查看家人、接收「立即定位」指令 | 手机 App | Kotlin + Compose + 高德定位 |
| Web 家庭端 | 家庭成员 | 大屏看位置、轨迹回放、家庭 / 设备管理 | 桌面 / 手机浏览器 | Vue3 + 高德 JS API |
| 服务端 | 部署者 | 账号、家庭、位置存储、指令下发 | 家中设备 + 内网穿透 | Node.js + Fastify + SQLite |
| 管理后台（P2） | 部署者 | 用户 / 家庭 / 设备 / 日志 | Web | 同 Web 家庭端 |

**为什么两个查看端**：手机 App 适合随时随地看；Web 适合在家或办公室大屏查看与配置。两端共用同一套服务端 API。

## 5. 信息架构与导航

**Android App**（底部 3 个 Tab）：

```
地图（首页）── 成员详情卡 / 历史轨迹
家庭 ──────── 家庭管理 / 邀请成员
设置 ──────── 账号 / 位置共享 / 权限自检 / 隐私 / 关于
```

**Web 家庭端**（左侧导航）：

```
地图 ── 成员详情抽屉 / 轨迹回放
家庭 ── 成员管理 / 邀请
设备 ── 设备列表 / 解绑
设置 ── 账号 / 数据保留 / 危险操作
```

**首次使用路径**：登录 → 创建 / 加入家庭 → 权限引导（3 步）→ 家庭地图。

## 6. 页面详细说明

### 6.1 Android App（画板 390 × 844）

#### A00 启动页（可选）

- **目标**：冷启动时展示品牌与加载状态。
- **布局**：品牌色 / 浅色背景居中，圆形定位图标 + 「你在哪」+ 一句 slogan「和家人保持联系」。
- **状态**：0.8s 内跳转登录页或地图页（已登录且有家庭）。

#### A01 登录

- **目标**：登录已有账号。
- **布局**：垂直居中表单。
- **元素**：
  - Logo + 产品名 + 副标题。
  - 用户名输入框、密码输入框（带可见切换）。
  - 主按钮「登录」（全宽）。
  - 文字链接「没有账号？注册」。
  - 右上角齿轮图标 → 服务器地址设置（弹窗：`https://your-domain`）。
- **状态与交互**：空态 / 输入中 / 登录中（按钮 loading）/ 错误提示（账号或密码错误、网络不可达、服务器地址未配置）。登录成功 → 有家庭进 A07，无家庭进 A03。

#### A02 注册

- **目标**：创建账号。
- **元素**：用户名、昵称、密码、确认密码、邀请码（选填，6 位）、主按钮「注册」、「已有账号？登录」。
- **状态**：字段校验（用户名 3–20 位、密码 ≥ 8 位、两次一致）；邀请码无效 / 过期时的行内提示；注册成功后按是否填邀请码进入 A07 或 A03。

#### A03 创建 / 加入家庭

- **目标**：没有家庭时二选一。
- **布局**：标题「加入一个家庭」+ 两张卡片。
- **卡片 1 · 创建家庭**：家庭名输入 + 「创建」按钮（创建者成为管理员）。
- **卡片 2 · 加入家庭**：6 位邀请码输入 + 「加入」按钮。
- **说明文字**：一个账号同一时间只能加入一个家庭；邀请码由家人提供。
- **状态**：邀请码无效 / 已过期 / 家庭已满；创建中 loading。

#### A04 权限引导 ① 前台定位

- **目标**：拿到使用期间定位权限。
- **布局**：插画（定位图标 + 家人地图示意）+ 标题「允许获取你的位置」+ 说明「用于把你的位置分享给家人，仅家庭成员可见」+ 主按钮「允许」+ 次按钮「暂不」。
- **状态**：点击「允许」触发系统权限弹窗；已授权自动进入下一步；点「暂不」提示「不授权将无法共享位置」，可稍后在设置中开启。

#### A05 权限引导 ② 后台定位与通知

- **目标**：拿到「始终允许」定位与通知权限。
- **布局**：标题「锁屏后也能更新位置」+ 说明 + 两个权限条目。
- **元素**：
  - 条目 1「后台定位」：状态徽标（未授权 / 已授权）+ 「去设置」→ 系统设置选择「始终允许」。
  - 条目 2「通知」：说明常驻通知是系统要求，表示共享正在进行；「去授权」→ 系统弹窗。
- **状态**：任一未授权时，主按钮变为「稍后再说」；两项都完成才高亮「下一步」。

#### A06 权限引导 ③ 保活自检

- **目标**：引导国产 ROM 用户完成自启动 / 电池白名单设置。
- **布局**：标题「让共享保持在线」+ 说明「部分系统会清理后台应用」。
- **元素**：
  - 品牌选择（默认自动识别）：小米 / 红米、华为 / 荣耀、OPPO / 一加、vivo / iQOO、其他。
  - 按品牌展示 2–3 步图文步骤 + 「去设置」。
  - 「忽略电池优化」条目 + 授权按钮。
  - 主按钮「完成，开始共享」。
- **说明**：可稍后在「设置 → 权限自检」重新配置。

#### A07 家庭地图（首页，核心）

- **目标**：一屏看到全家位置。
- **布局**（层叠）：
  1. 顶部栏：左侧家庭名 + 「n 人在线」；右侧刷新图标。
  2. 成员横向列表：圆形头像 44px + 昵称 + 状态点（在线绿 / 离线灰 / 定位中橙脉冲），选中项主色描边。
  3. 全屏地图（高德）。
  4. 底部状态卡（未选中成员时）：「我的共享」+ 状态（共享中 / 已暂停）+ 最后更新时间 + 当前地址 + 「暂停共享」按钮。
  5. 右下角悬浮按钮：回到我的位置；图例。
- **地图元素**：成员标记（头像 + 状态色环）、我的蓝点、精度圈、选中放大。
- **状态**：
  - 加载中（骨架 / 地图 loading）。
  - 无其他成员：底部卡片换成「邀请家人一起使用」+ 按钮。
  - 权限异常：顶部黄色横幅「后台定位未开启，位置可能不及时」+ 「去修复」。
  - 服务端不可达：顶部灰条「连接中断，正在重试」。
- **交互**：点标记 → 打开 A08；拖动地图取消跟随；点刷新 → 拉取最新位置。

#### A08 成员详情卡（底部抽屉）

- **目标**：查看单个成员的详细位置信息与操作。
- **布局**：拖拽把手 + 头像 / 昵称 / 在线状态 + 地址（大字）+ 指标网格 + 操作按钮。
- **指标**：最后更新时间（「1 分钟前」）、精度（±12m）、电量（78%）、速度、坐标（可复制）。
- **按钮**：主按钮「立即定位」；次按钮「历史轨迹」；文字按钮「导航」（唤起高德 / 系统地图）。
- **立即定位状态**：
  - 请求中：按钮 loading + 「正在请求对方定位…」。
  - 成功：更新时间刷新 + toast「已获取最新位置」。
  - 失败：提示「对方离线 / 未开启定位 / 请求超时」。
- **关闭**：下滑或点地图空白处。

#### A09 历史轨迹

- **目标**：查看某个成员某天的移动路线。
- **布局**：顶部（返回 + 成员名 + 日期选择：今天 / 昨天 / 选择日期）+ 地图 + 底部信息栏。
- **地图**：轨迹折线 + 起点 / 终点标记。
- **底部**：里程、时长、首末时间；「回放」按钮（P1，M1 置灰）。
- **状态**：当天无轨迹的空态；加载中；日期不可选未来。

#### A10 家庭管理

- **目标**：管理家庭成员与家庭信息。
- **布局**：
  - 家庭名 + 编辑图标（仅管理员）。
  - 成员列表：头像、昵称、「我」/「管理员」标签、在线状态、共享状态（共享中 / 已暂停）；管理员可点更多菜单「移除成员」。
  - 主按钮「邀请家人」→ A11。
  - 底部危险操作「退出家庭」（红色，二次确认）。
- **状态**：成员为空（仅自己）时的邀请引导。

#### A11 邀请成员

- **目标**：把家人拉进家庭。
- **元素**：
  - 6 位邀请码大字展示 + 复制按钮。
  - 二维码（家人用 App 扫码或输入）。
  - 有效期说明「24 小时内有效」+ 管理员可见「重置邀请码」。
  - 主按钮「分享给家人」（系统分享）。
- **状态**：复制成功 toast；重置后旧码立即失效提示。

#### A12 设置

- **目标**：账号、共享、权限与隐私的集中管理。
- **分组**：
  1. **账号**：头像、昵称、用户名；修改密码（P1）。
  2. **位置共享**：总开关；上报频率（省电 10 分钟 / 标准 3 分钟 / 高频 1 分钟）；后台运行状态。
  3. **权限自检**：定位、后台定位、通知、电池优化、自启动五项，每项状态图标 + 「去设置」。
  4. **通知**（P1，置灰）。
  5. **隐私与安全**：隐私政策、清除我的历史位置。
  6. **关于**：版本号、服务器地址。
  7. **退出登录 / 注销账号**（红色）。
- **状态**：开关切换即时生效并在首页同步；关闭共享后家人端显示「已暂停」。

### 6.2 Web 家庭端（画板 1440 × 900）

#### W00 登录

- **布局**：浅色背景，居中卡片（420px）。
- **元素**：Logo + 「你在哪」+ 副标题；用户名、密码；「登录」主按钮；服务器地址（折叠在「高级」里）；底部版本号。
- **状态**：错误提示（账号密码错误 / 服务端不可达）。

#### W01 家庭地图（主界面，核心）

- **布局**：顶栏 64px + 左侧成员面板 320px + 地图区域 + 右侧详情抽屉（选中成员时 360px）+ 右下角地图控件。
- **顶栏**：Logo、家庭名、「n / m 人在线」、刷新按钮、用户菜单（设置 / 退出）。
- **左侧成员列表**：搜索（P1）；每个成员卡片：头像 + 状态点、昵称、当前地址（单行省略）、相对时间、电量条。
- **地图**：成员标记、我的位置、精度圈、选中高亮。
- **右侧抽屉**：见 W02。
- **右下角**：缩放控件、「查看全家」按钮。
- **状态**：
  - 空态：家庭无其他成员 → 中央邀请卡片。
  - 服务端连接异常：顶部黄色横幅。
  - 成员离线 / 位置过期：灰色标记 + 「最后在线 x 分钟前」。

#### W02 成员详情抽屉

- **布局**：右侧 360px，顶部关闭按钮。
- **元素**：大头像 + 昵称 + 在线状态；地址（大字）；指标：更新时间、精度、电量、速度、设备名；按钮「立即定位」（主）、「查看轨迹」（次）、「导航」（文字链）。
- **状态**：同 A08 的请求中 / 成功 / 失败三态。

#### W03 轨迹回放

- **布局**：顶栏（返回地图 + 成员名 + 日期选择）+ 地图 + 底部时间轴（120px）。
- **地图**：轨迹折线 + 起终点 + 当前位置点。
- **时间轴**：播放 / 暂停、倍速（1x / 2x / 4x）、进度条、当前时间与地址标签。
- **侧边**：里程、时长、停留点列表（P1）。
- **状态**：无轨迹空态；加载中。

#### W04 家庭管理

- **布局**：内容区最大宽度 960px。
- **元素**：
  - 家庭名 + 编辑。
  - 成员表格：成员（头像 + 昵称）、角色、共享状态、最后在线、操作（移除 / 设为管理员，P1）。
  - 家庭动态：最近 7 天加入的成员。
  - 邀请卡片：邀请码、二维码、复制、重置（管理员）。
  - 危险区：退出家庭（成员）/ 解散家庭（管理员，P2）。
- **状态**：操作二次确认；无权限时按钮隐藏。

#### W05 设备管理

- **布局**：页头（含「绑定新设备」按钮）+ 说明条 + 表格。
- **列**：设备名、所属成员、型号、系统版本、App 版本、在线状态、最后心跳、操作（重命名 / 解绑）。
- **说明**：解绑后该设备立即停止上报，需重新登录绑定。
- **状态**：设备离线灰色行；解绑二次确认。

#### W06 设置

- **分组**：
  1. 账号资料（昵称、头像）、修改密码（P1）。
  2. 数据保留：保留天数（30 / 90 / 180 / 永久），仅管理员。
  3. 通知（P1）。
  4. 危险操作：清空家庭历史位置（管理员）、退出家庭。
- **状态**：保存成功 toast；权限不足时置灰。

## 7. 关键流程

### F1 首次使用

```
打开 App → 登录 / 注册 → 创建或加入家庭 → 权限引导（3 步）→ 开始共享 → 家庭地图
```

### F2 邀请家人

```
成员打开邀请页 → 生成 6 位码 + 二维码 → 分享 → 家人注册 / 登录
→ 输入邀请码 → 加入成功 → 双方地图互相可见
```

### F3 立即定位（核心时序）

```
Web / App            Server                      Android
   |--POST locate----->|                           |
   |                   |--WS {type: "locate"}----->|
   |                   |                           | 单次高精度定位
   |                   |<--POST /locations---------|
   |<--WS 位置更新------|                           |
   |  刷新地图          |                           |
```

- 超时 30 秒未回传 → 前端提示「对方离线或未开启定位」。
- 同一设备 30 秒内重复请求合并为一次。

### F4 查看历史轨迹

```
选成员 → 选日期 → GET /devices/:id/locations?from&to → 地图绘制折线 → （P1）回放
```

### F5 暂停 / 恢复共享

```
设置开关 或 通知栏操作 → App 停止 / 恢复上报 → 服务端广播状态 → 家人端显示「已暂停」
```

## 8. 状态与异常处理

| 状态 | 界面表现 | 用户操作 |
|---|---|---|
| 未登录 | 跳转登录页 | 登录 |
| 未加入家庭 | 跳转 A03 | 创建 / 加入 |
| 家庭无其他成员 | 地图空态 + 邀请卡片 | 邀请家人 |
| 前台定位被拒绝 | 无法开启共享，引导授权 | 去授权 |
| 后台定位被拒绝 | 黄色横幅「位置可能不及时」 | 去设置 |
| 通知权限被拒绝 | 提示常驻通知不可见，建议开启 | 去授权 |
| 电池优化未关闭 | 黄色横幅「系统可能清理后台」 | 去设置 |
| 系统定位关闭 | 红色横幅「请打开系统定位」 | 跳系统设置 |
| 无网络 | 本地缓存位置，恢复后补传；顶部灰条 | 等待自动重试 |
| 服务端不可达 | 「连接中断，正在重试」 | 自动重连 |
| 成员离线（>10 分钟） | 灰色标记 + 最后在线时间 | 立即定位 |
| 位置过期（>30 分钟） | 空心标记 + 「x 小时前」 | 立即定位 |
| 精度较差（>100m） | 大精度圈 + 「精度较低」 | 等待更新 |
| 立即定位失败 | 提示离线 / 未授权 / 超时 | 重试 |
| 被移出家庭 | 强制回到 A03 | 重新加入 |
| 邀请码无效 / 过期 | 行内错误提示 | 向家人要新码 |

### 9.3 形状、间距与层次

- **圆角**：按钮 / 输入框 / 分段器 8；成员卡、表格行、提示条 10–12；卡片 16；面板 / 抽屉 / 底部卡 20–24；引导插画及大容器 24–40；头像始终 50%（圆形）。
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48。手机左右安全边距 24，Web 内容区左右 48；区块间距 16–32，引导页保留大量留白。
- **层次（Depth）**：不使用多层阴影，层级由「1px 描边 + 柔面 / 粉彩底」表达：
  - 卡片：白底 + 1px `#E0E2E8` 内描边，圆角 16；
  - 次按钮：白底 + 1px `#C7CAD5`；
  - 输入框：白底 + 1px `#E9EAEF`；
  - 悬浮面板（地图顶栏、底部状态卡、Web 抽屉）：白底 + 1px 外环，必要时 95% 白（`#FFFFFFF2`）；
  - 仅浮起的小控件（地图圆形按钮）允许极轻的单层阴影，禁止叠加。
- **按钮**：主按钮 Blue 450、8px 圆角、高 42–52；次按钮白底 1px `#C7CAD5`；白色圆形按钮 50% 圆角 + 1px 环；禁用态为 `#F7F7F9` 底 + `#A5A8B5` 文字，不整块降透明度。
- **输入框**：白底、1px `#E9EAEF`、8px 圆角、左右内边距 14–16、高 40–52；聚焦以 Blue 450 描边表示（原型静态展示默认态）。
- **选中态**：导航 / 分段器 / 成员卡使用 `#5B76FE1F` 浅蓝底 + Blue 450 文字与图标（必要时 1px Blue 450 描边）。
- **交互态**：按下统一 `#2A41B6`；Web hover 仅做轻微加深，不新增色值；危险操作必须二次确认。
