# 你在哪 · v1.1.0（M1）

家庭位置共享 Android 应用 + 自建服务端 + Web 家庭端。

## 安装

- 适用：Android 8.0+（minSdk 26）；已在 Redmi K100 Pro / Android 17、华为 Mate 20 Pro / Android 10 真机验证。
- APK：`where-are-u-1.1.0.apk`（v1.0.0 首个发布版；v1.0.1 登出文案与成员邀请入口；v1.0.2 默认 HTTPS；v1.0.3 修复地址偏移；v1.0.4 新增「关注」提醒；v1.1.0 新增家庭地点与到达/离开提醒）
- 安装：允许「安装未知来源应用」后直接安装，或：
  ```bash
  adb install -r where-are-u-1.1.0.apk
  ```
- 首次打开：注册账号 → 创建家庭（或输入家人的 6 位邀请码加入）→ 按引导开启定位/后台定位/通知 → 开始共享。
- 默认服务器已在构建时写入 APK；也可在登录页右上角齿轮里修改。

## 服务器地址与 HTTPS

- 默认：`https://182.254.155.179`（Let's Encrypt IP 证书，nginx 终止 TLS 后经 frp 转回家中 NAS）
- 从 v1.0.1 升级上来的设备，本地保存的 `http://182.254.155.179:18080` 会在启动时**自动迁移**为 HTTPS 默认地址；用户自己填过的其他服务器不会被改动。
- 旧的 `http://182.254.155.179:18080` 仍可用，仅用于过渡；新装设备一律走 HTTPS。

## 真机一键验收（v1.1.0）

连接手机、开启 USB 调试后，在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File release\verify-redmi.ps1 -Apk release\where-are-u-1.1.0.apk
```

可选参数：`-Serial <设备序列号>`、`-Apk <APK路径>`、`-Username <账号> -Password <密码>`（传账号密码时会额外触发一次立即定位并等待 completed）。

脚本会安装 APK、校验版本、依次点击「家庭 / 设置 / 地图」并检查进程与崩溃日志；截图输出到 `%TEMP%\whereareu-*.png`，全部通过时退出码为 0。

## 本版功能

- 注册 / 登录、家庭创建、6 位邀请码加入
- 3 步权限引导（前台定位、后台定位 + 通知、电池/OEM 自启动）
- 家庭地图、成员详情、实时位置、电量、精度、最后更新时间
- 立即定位：Web/家属端下发指令，手机单次高精度定位并回传
- 历史轨迹（日期、折线、里程/时长）
- 家庭管理、邀请、设备列表、设置
- 前台定位服务、自适应上报、断网队列补传
- 共享暂停/恢复，服务端同步 `sharingPaused`
- 退出登录解绑本机设备并停止共享；成员端不显示管理员专属邀请入口（v1.0.1）
- **关注与提醒（v1.0.4）**：关注家人后可设置「位置变动（阈值/冷却）」「长时间未更新」「低电量」三类规则；事件由服务端评估，经设备长连接实时下发，App 弹系统通知并写入消息中心；对方可在「谁在关注我」里看到关注者
- 位置变动为漂移基准：以上次通知时的位置比较，冷却期内不重复；夜间低电量只进消息中心，不弹通知
- **家庭地点与地理围栏（v1.1.0）**：
  - 地图长按（Web 桌面端右键）添加家 / 学校 / 公司等地点，半径可选 100/200/500/1000 米；地点全家共享，创建者或管理员可编辑/删除
  - 关注规则新增「到达 / 离开某地」：支持到达、离开、到达和离开；可为每条规则设置生效时段（星期 + 起止时间，北京时间，支持跨天）
  - 围栏判定带迟滞与精度过滤，关注、恢复共享、修改地点后的第一个点只建立基线；删除地点会同时移除引用它的围栏规则
  - 地图上显示地点圆与名称标记；设置页可管理全部地点
  - 平台一次性定位回退的 GPS 点已统一转换为 GCJ-02，避免围栏偏移约 400–500 米

## 签名说明（重要）

v1.0.0 / v1.0.1 / v1.0.2 / v1.0.3 / v1.0.4 / v1.1.0 使用**调试证书**签名，目的是匹配高德 Android Key 当前登记的调试 SHA1。它适合家庭侧载，不适合应用商店或正式分发。

升级为正式分发时：

1. 生成正式 release keystore；
2. 在高德控制台为 `com.whereareu.app` + release SHA1 新增 Android Key；
3. 在 `android/local.properties` 写入 release keystore 与新 Key；
4. 构建 release APK 并在真机复测地图/定位。

## 已知限制

- 公网入口为 **HTTPS**（`https://182.254.155.179`，Let's Encrypt **IP 证书**，7 天有效期、宝塔每日自动续期）。IP 证书无需域名，但部分老旧客户端对 IP SAN 支持不佳；长期建议换域名。
- 服务端到家中 NAS 之间经 frp 隧道传输，TLS 在 VPS 的 nginx 终止。若要求端到端加密，需在 frp 上再套一层 TLS。
- AMap 10.0.600 的原生库为 4KB 页对齐：本机 Redmi K100 Pro（4KB 页）已验证通过；16KB 页内核的新机型存在地图/定位加载失败风险，需等高德提供 16KB 对齐版本。
- 无 iOS 客户端；无 SOS。
- 提醒依赖 App 的前台定位服务与设备长连接：App 被系统彻底杀掉时不会弹系统通知，但消息仍保存在「消息」里，下次打开补拉；没有 FCM/离线推送（国内不可靠）。
- Web 桌面通知只在页面打开时有效，需要用户点击「开启桌面通知」授权。
- 地点选点依赖高德地图；未配置/未加载高德时使用离线示意地图，此时不能在地图上添加地点（已有地点仍可在设置页管理）。
- 地理围栏按 GCJ-02 坐标判定；平台一次性定位回退只转换 GPS 原始点，个别国产 ROM 的 fused/网络定位可能已自带偏移，精度差时会由精度过滤兜底。
- 围栏告警是服务端判定，仍受「被关注者是否在上报」影响；对方暂停共享或手机离线时不会产生进出事件。
- HyperOS / MIUI 需要在系统中给「你在哪」开启自启动、省电无限制，否则锁屏后可能被系统清理（App 内有权限自检入口）。
- 历史保留天数、清空历史、家庭改名等接口不在 M1 契约内。
- 位置为高德 GCJ-02 坐标，地址由设备侧逆地理编码。
